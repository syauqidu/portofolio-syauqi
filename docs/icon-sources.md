# Icon sources

Icons are rendered as local SVG at build time. No icon CDN or browser-side icon library is required.

- General interface icons: [Lucide](https://lucide.dev/), distributed through `@iconify-json/lucide` (ISC). Used for Home, Download, Mail, the small train, and non-product concepts.
- Technology and social logos: [Devicon](https://github.com/devicons/devicon), distributed through `@iconify-json/devicon` (MIT). Original shapes and colors are retained. Logos identify the tools and platforms; they do not imply endorsement.
- Katalon mark: [SVG Logos source](https://github.com/gilbarbara/logos/blob/main/logos/katalon-icon.svg), stored as `public/katalon.svg`. The SVG Logos collection is CC0; the Katalon brand remains the property of its owner. [Katalon brand assets](https://www.katalon.com/brand-assets).

Collection license metadata is included in each installed package's `info.json`; keep these packages and their lockfile together. Icon components are decorative when accompanied by text. Icon-only links require a meaningful accessible label on the link itself.
